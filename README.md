# attention-game-unity

### Summary
This is a 2D, UI-based simulation game, where the player is a high school student struggling with ADHD. 
My goal is to highlight some of the struggles a teenager with undiagnosed ADD could face, using my own personal experience as a reference. 
I hope to produce a fast-paced, (hopefully) humorous, story about a person trying to make it through school with a limited attention span.

This is currently still in the early development stages, and I plan to work on it regularly.


### Plugins/Assets
This project uses the following plugins/assets:
  - OdinInspector from Sirenix
  - UniTask
  - Violet Theme Ui asset bundle (for placeholder sprites)
